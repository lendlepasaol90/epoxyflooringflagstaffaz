# Epoxy Flooring Flagstaff

Source for epoxyflooringflagstaffaz.com. Pages are generated by `build.mjs` into `public/` and served by a Cloudflare Worker (`src/worker.js`), which also receives the estimate form at `/api/lead`.

## Pages

- `/`
- `/winter-garage-floor-coatings/`
- `/home-floor-coatings/`
- `/flake-chip-floors/`
- `/polyaspartic-coatings/`
- `/polyurea-coatings/`
- `/porch-patio-concrete-coatings/`
- `/commercial-flooring/`
- `/industrial-floor-coatings/`
- `/about-our-crew/`
- `/where-we-work/`
- `/free-estimate/`
- `/privacy-policy/`

Service pages live in `src/content/services/` (one file per page, registered in `index.mjs`).
